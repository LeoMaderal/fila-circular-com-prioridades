# Fila Circular com Prioridades

Projeto acadêmico desenvolvido em **C++** para simular o processamento de tarefas em **4 processadores**, utilizando filas circulares com prioridade.

## Sobre o projeto

As tarefas são lidas do arquivo `Trabalho.txt` e distribuídas entre os processadores de acordo com suas prioridades.

O programa simula o processamento das tarefas e, ao final, apresenta informações sobre o atendimento de cada processador.

## Conceitos utilizados

* C++
* `struct`
* Vetores e ponteiros
* Filas circulares
* Filas com prioridade
* Manipulação de arquivos
* Funções

## Arquivos

```text
Trabalho_1Bim.cpp  → Programa principal
filaP.h            → Implementação da fila
Trabalho.txt       → Dados das tarefas
```

## Como executar

O projeto foi desenvolvido no **Dev-C++**.

1. Abra o `Trabalho_1Bim.cpp`.
2. Verifique se o `Trabalho.txt` está no local correto.
3. Compile e execute o programa.
